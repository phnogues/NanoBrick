nanoBrick — remote

4 receivers × 2 outputs = 8 motors · ESP32 + nRF24 plugged in over USB (Arduino transmitter)

This browser does not support the serial port (Web Serial).
Open this page in Chrome or Edge.

Not connected
Each receiver has its selector set to 1, 2, 3 or 4 and drives 2 motors (outputs A and B). A click sends the chosen number of notches; about twenty give full speed. The number is an estimate (the receiver sends nothing back).
Keyboard (receiver 1): output A W or Z / S, output B ↑/↓, stops A and P, stop all Space.
While the page is connected, the ESP32 keeps transmitting for the receivers present (steady light). Disconnect before using an original remote again.
